# AI Tools Used Disclosure

 AI tools used to support parts of the development of the Aarohan Residency – Hotel Room Booking System.

---

## 1. Tools Used

| Tool Name | Version / Plan | Purpose | How It Was Used |

| ChatGPT  | Project planning and technical discussions | Used for architecture structuring, reviewing requirements, discussing possible approaches, drafting development plans/prompts, and organizing the workflow. |
| Claude | Development and documentation assistance | Used for code-generation support in ASP.NET Core MVC, EF Core model/migration assistance, UI implementation support, and repository documentation assistance. |

---

## 2. Purpose of AI Assistance

AI tools were used selectively as supporting utilities for parts of the implementation, boilerplate generation, technical guidance, and documentation drafting—not as the owner or designer of the application.

---

## 3. Developer Responsibilities and Contributions

The developer directed the project and remained responsible for:

- Understanding project requirements and defining application functionality and priorities.
- Making architectural, technology, and technical decisions.
- Directing implementation, reviewing and adapting generated code, and resolving build or configuration issues.
- Testing application functionality, database behavior, and booking logic.
- Reviewing the guest and admin UI, making improvements, and validating the final submission.

---

## 4. AI Usage Transparency

AI assistance supported specific implementation and documentation tasks during development. database structures, and documentation were reviewed and validated by the developer.
